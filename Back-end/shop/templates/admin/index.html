Welcome to the Laceloft shop manager

This is where you manage the products customers see on the website. Changes to products appear on the website straight away, so there is nothing technical to do.

+ Add a new pair See all products

Common jobs

  1. Add a new pair. Press Add a new pair. Fill in the name, price and sizes, type how many you have in each size, add photos, then press Save.
  2. Change a price or mark a pair sold out. Open Products, change the price or untick Available in the table, then press Save at the bottom.
  3. A pair has sold. Open the product and lower the number under Stock per size. A size at 0 shows as sold out.
  4. Hide a pair from the shop. Untick Available to order and save. It is better than deleting, because you can switch it back on later.
  5. After adding or renaming a product. Open Products and press Publish to website once. This only updates link previews on WhatsApp and Google; the product is already live.

Good to know

  • Orders are not taken here. Customers message the shop on WhatsApp, so you update stock numbers yourself.
  • Photos look best as portrait pictures in a 4:5 shape, for example 1200 x 1500 pixels. The first photo is the one shown on the shop page.
  • Category is a tag such as Boots or Sandals. Customers use categories to filter the shop.
  • Product code (SKU) is a short unique name such as AD-SMB-BRN. It becomes part of the web address, so it cannot be changed after saving.
  • Need to log out? Use Log out at the top of the page, especially on a shared phone or computer.
